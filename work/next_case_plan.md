## 1. How to Add the Next Case Study (Standard Template)
Every new project added to the site follows the 3-beat structure:
1. **Problem:** What real-world constraint or inefficiency needed solving?
2. **Action:** What technical stack, data engineering, or ML modeling did I implement?
3. **Outcome:** What was the quantitative impact or measurable metric (e.g., % error reduction)?

### Workflow Steps to Publish:
* Create a dedicated subfolder under `projects/` inside the local repository.
* Document code and artifacts via a concise `README.md`.
* Append a new project card into `index.html` using preserved layout styles.
* Commit and push to `main` for automatic GitHub Pages deployment.
